# Development parsing Golden Dataset

This manifest intentionally contains no copyrighted or proprietary PDF. Add only local or
evaluation-approved sources and record their SHA-256 digest. The target corpus is 20–50 difficult
pages across born-digital, image-only and OCR-layer scans, Chinese, English, bilingual, two-column,
rotated, cropped, table, merged-cell, financial, cross-page-table, and noisy-scan slices.

An empty committed manifest means the benchmark code is ready but provides no accuracy evidence.
